# MTF公益机场 · 政务风 UI 改版

基于 2026-09-26 的 UI 交接包（`MTF-UI-STATIC-2026-09-26.zip`）重新设计的完整静态网站：朱红、鎏金、宣纸色，宋体标题，红头文书公告，原创站徽与祥云、回纹、长城纹样，另有藏青配色可一键切换。

**打开 `site/index.html` 即可离线浏览**，不需要服务器；所有数据为虚构示例，不连接生产 API。

## 覆盖范围

登录、邀请码注册（含 Telegram 申请步骤）、忘记密码、仪表盘 / 订阅、使用文档（七篇全文）、每日签到、流量排行、节点状态、六台物理机带宽看板、个人中心、Telegram 绑定、我的邀请、工单、流量明细，以及管理员的运维总览（按物理机汇总）、用户与 IP（含行为详情）、批量邀请码、封禁、公告。

业务规则按交接要求保留：注册需要邀请码、登录不需要；每月保底 60 GB，签到每天固定 +2 GB；每来源 IP 最高 100 Mbps；cn2gia救命线路按 1.8 倍扣配额；订阅链接只显示打码形式；Telegram 新用户 7 天内绑定、绑定码 30 分钟有效；排行只显示打码邮箱；带宽看板明确「北京参考 RTT 不等于用户侧延迟」；公告同步 Telegram 主群。钱包、购买、订单入口没有恢复。

状态齐全：输入错误、加载中、空列表、已签到、节点离线、网络错误、登录失效、未绑定 / 绑定成功、确认弹窗、额度告急。

## 使用

- 右上角切换「朱红 / 藏青」；打开「接口标注」可在页面上直接看到每个控件对应的接口。
- 窗口不超过 760px 自动切换手机布局：顶部红色标题栏 + 底部标签栏（首页 / 签到 / 带宽 / 绑定 / 更多）。

## 关于标识

站徽为原创设计，不使用国徽、党徽、警徽或任何机关名称；公告落款与印章均为「MTF公益机场站务组」自己的名义。

## 上线

本仓库只包含设计与静态原型。线上是 XBoard + MtfCore 插件；接入已经做完，以上线包 `MTF-gov-theme-2026-09-26.zip` 单独交付（含服务端源码，不放公开仓库），在面板机上执行 `bash mtf-frontend-deploy.sh deploy <MtfCore 目录>` 即可上线，`rollback` 一键回退。做法与差异见 `docs/INTEGRATION.md`。
