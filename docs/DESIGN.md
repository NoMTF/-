# 视觉规范摘要

完整可视版本见 `site/styleguide.html`。

## 方向

借用政务门户与公文的视觉语言：朱红与鎏金、宋体标题、栏目式标题、红头文书、印章、祥云与回纹。内容和语气仍然是公益机场自己的，顶部公告条用站内标语（如「坚持公益定位，建设带宽强站！」）。

**不冒用官方标识**：站徽是原创设计（五星、双翼代表「机场」、月桂、联珠纹），不使用国徽、党徽、警徽，也不出现任何机关名称。公告落款为「MTF公益机场站务组」，文号为「MTF站发〔2026〕N号」，印章文字为站务组自己的名称。

## 字体

- 标题、数据：思源宋体（Noto Serif SC）900 / 700
- 正文：思源黑体（Noto Sans SC）
- 标语、签到印章：马善政毛笔楷书（Ma Shan Zheng）
- 凭证、IP：系统等宽字体

三款字体均为 SIL Open Font License 1.1，许可证在 `site/assets/fonts/`。

## 纹样与图形

全部内联在 `gov-art.css`（CSS 变量 `--emblem`、`--pat-cloud`、`--pat-fret`、`--pat-skyline` 等），离线可用：站徽（朱红 / 藏青两版）、祥云底纹、回纹、长城剪影；光芒用 `repeating-conic-gradient` 绘制；印章是页面内联 SVG。

## 图标

79 个 24×24 线性图标，1.8 描边，用 CSS 遮罩着色：`<i class="i i-home"></i>`，大小 `.sm` `.lg` `.xl`。

## 布局

- 桌面：侧栏 256，内容最宽 1200、两侧 32；顶栏 64，下接公告条。
- 手机（≤760px）：红色顶栏 60 + 底部标签栏；侧栏变抽屉；多列变单列；宽表格改为卡片（`.table.to-cards`）或横向滚动。
