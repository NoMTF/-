# 页面与状态清单

打开 `site/index.html` 可以看到带缩略图的总览。截图在 `site/screenshots/desktop/`（1440 宽）和 `site/screenshots/mobile/`（390 宽，2 倍图）。

## 页面

| 页面 | 文件 | 说明 |
|---|---|---|
| 登录 | `login.html` | 不需要邀请码；输入错误状态见状态样张 01 |
| 邀请码注册 | `register.html` | 邀请码必填、邮箱验证码、两次密码、条款勾选；Telegram 申请邀请码五步流程 |
| 忘记密码 | `forgot.html` | 三步流程条、邮箱验证码 |
| 仪表盘 | `dashboard.html` | 额度环形表、订阅链接（打码）、重置确认、三项规则、快捷办理、待办、通知公告（红头文书弹窗）、推荐线路 |
| 使用文档 | `docs.html` | 七篇全文，桌面目录 / 手机下拉切换 |
| 每日签到 | `checkin.html` | 签到印章，点击后变「已签」；九月签到日历；四条规则 |
| 流量排行 | `ranking.html` | 今天 / 昨天 / 前天 / 6 天前，切换有骨架加载；6 天前为空状态；自己的名次单独一行 |
| 节点状态 | `nodes.html` | 六台物理机、三协议、倍率说明、离线卡片、故障切换分组、协议选择 |
| 带宽看板 | `bandwidth.html` | 全站占用、北京探测点 RTT 示意（手机隐藏）、每台八项指标、RTT 不等于用户侧延迟的醒目说明 |
| 个人中心 | `profile.html` | 站友证、服务状态、改密码、在线设备、重置订阅、隐私说明 |
| Telegram 绑定 | `telegram.html` | 截止倒计时、绑定码、30 分钟倒计时、复制 `/bind`；点「已发送？检查状态」切到已绑定 |
| 我的邀请 | `invites.html` | 邀请函、须知、使用记录空状态、申请流程 |
| 我的工单 | `tickets.html` | 状态筛选、对话、新建工单（节点 / 协议 / 客户端） |
| 流量明细 | `traffic.html` | 14 天堆叠柱状图（悬停提示）、近 7 天表格、1.8x 多扣配额 |
| 运维总览 | `admin.html` | KPI、按物理机汇总的负载表、最近连接、需要关注 |
| 用户与 IP | `admin-users.html` | 筛选、用户表、行为详情（1 小时快照、5 天汇总）、封禁确认弹窗 |
| 邀请码生成 | `admin-invites.html` | 数量步进器、生成结果、邀请码池、发放记录 |
| 封禁管理 | `admin-bans.html` | 账户 / IP / 域名规则、范围、时长、当前生效列表 |
| 公告管理 | `admin-notices.html` | 编辑器 + 红头文书实时预览、Telegram 同步状态 |
| 视觉规范 | `styleguide.html` | 色彩、字体、站徽纹样、组件、图标、版式 |
| 状态样张 | `states.html` | 下表所列状态的集中展示 |

## 交接要求中的状态

| 状态 | 在哪里看 |
|---|---|
| 输入错误 | 登录 / 注册 / 忘记密码 / 改密码 / 新建工单直接点提交；状态样张 01 |
| 加载中 | 流量排行切换日期；签到、检查绑定按钮；状态样张 02 |
| 空列表 | 流量排行「6 天前」、我的邀请使用记录、工单「已关闭」筛选；状态样张 03 |
| 已签到 | 签到页点印章；状态样张 04 |
| 节点离线 | 节点状态、带宽看板、运维总览中的日本节点（2）；状态样张 05 |
| 网络错误 / 登录失效 | 状态样张 06 |
| 未绑定 / 绑定成功 | Telegram 绑定页默认未绑定，点「已发送？检查状态」变为已绑定；状态样张 07、08 |
| 轻提示、确认弹窗、公告文书、手机抽屉 | 所有按钮；状态样张 09–12 |
| 额度告急 | 状态样张 13 |

## 全局开关

- **朱红 / 藏青**：顶栏右侧切换，记在本地。
- **接口标注**：顶栏「接口标注」，虚线框控件上方显示对应后端接口。
- **手机布局**：窗口宽度不超过 760px 自动切换，也可直接用手机打开。
