办事指南 · 第一篇

三分钟连上：下载客户端 → 导入订阅 → 选节点

发布：MTF公益机场站务组更新：2026-09-22阅读约 3 分钟

1. 装客户端

按你的设备挑一个，优先选支持故障切换的（表中标「故障切换」的）：

平台推荐说明
WindowsClash Verge Rev / v2rayN故障切换 Verge 支持自动故障切换
macOSClashX Meta / Mihomo Party故障切换
AndroidClash Meta for Android / NekoBox故障切换
iOSShadowrocket（付费）/ Stash故障切换
为什么强调 Clash 系：我们在订阅里预置了故障切换分组，某个节点挂了，客户端会在 60 秒内自动切走，你基本无感。用纯 URI 订阅的客户端（如部分 v2rayN 配置）拿不到这个能力。

2. 复制订阅链接

仪表盘 →「我的订阅」→ 复制订阅地址。这个链接等于你的账号密码，别发给别人。

3. 导入并选分组

导入后在策略组里选：

  • MTF · 1x 优先：日常节点，故障时在 1x 节点间切换
  • MTF · 1.5x 优先：先选日本原生节点，故障时切到 1x
  • MTF · 1.8x 优先：先选 cn2gia救命线路，故障时切到 1.5x、1x
  • MTF · 2x 优先：先选原生双 ISP 家宽，再逐级切换
  • MTF · 自动择优：纯按延迟自动挑，不管倍率

4. 测试

访问 https://www.google.com 能打开就成了。连不上先看第五篇《连不上 / 速度慢》。

5. 绑定 Telegram

注册后 7 天内需要加入主群并绑定 Telegram。登录官网，点左侧「Telegram 绑定」领取绑定码；完整步骤见第二篇。

办事指南 · 第二篇

Telegram 绑定：加群、领码、验证

发布：MTF公益机场站务组更新：2026-09-23阅读约 2 分钟

注册完成后，7 天内加入主群并绑定 Telegram。申请邀请码时私聊过机器人，和注册后绑定官网账号是两件事；注册完成还需要做下面几步。

  1. 点击加入 MTF 主群，确认自己已经在群里。
  2. 登录官网。电脑和手机都打开左侧菜单「Telegram 绑定」；手机也可以点底部标签栏的「绑定」。页面会显示你的绑定码和「复制 /bind 指令」按钮。
  3. 点「复制 /bind 指令」，私聊 @MTFLink_bot，粘贴发送。完整格式是 /bind 你的绑定码。也可以在主群发送，机器人会尝试删除群内消息，但别人可能短暂看到，建议私聊。
  4. 机器人回复「绑定成功」后，回官网点击「已发送？检查状态」；看到「Telegram 已绑定」就完成了。

绑定码 30 分钟有效、一次性使用。过期就在官网刷新领取新码；机器人说「未加入主群」时，先确认加入的是上面的主群，再重发。已经绑定的账号无需重复领取。需要帮助可在主群咨询，不要把绑定码或订阅链接发给其他人。

办事指南 · 第三篇

节点怎么选：倍率是什么意思

发布：MTF公益机场站务组更新：2026-09-25阅读约 4 分钟

倍率与流量扣除

倍率不决定最高速度，也用于故障切换分组。新 cn2gia救命线路按 1.8 倍扣流量；其他节点保留原来的 1:1 计量：

节点标签限速算法跑 1 GB 扣多少
日本节点（1）1x每 IP 最高 100 Mbps，按实测负载调整1 GB
日本节点（2）1x每 IP 最高 100 Mbps，按实测负载调整1 GB
香港移动优化1x每 IP 最高 100 Mbps，按实测负载调整1 GB
日本原生节点1.5x每 IP 最高 100 Mbps，按实测负载调整1 GB
cn2gia救命线路1.8x每 IP 最高 100 Mbps，按实测负载调整1.8 GB
日本原生双 ISP 家宽2x每 IP 最高 100 Mbps，按实测负载调整1 GB

只有 cn2gia救命线路是 1 GB 扣 1.8 GB。其他节点仍是 1 GB 扣 1 GB；2x 节点目前也按 1:1 扣量。线路的实际速度仍受各自带宽、中国方向路由和实测负载影响，官网「带宽看板」可查看六台机器当前占用和每 IP 限速。

每 IP 最高 100 Mbps；连接人数不用于平分带宽。有人用不到 100 Mbps，不会因此拉低别人的上限。机器实测接近满载时才逐步调低，负载回落后自动回升。

各节点适合干什么

  • 日本节点（1）[1x]：原日本干净高速。流媒体全部日本原生解锁，ChatGPT 网页版可用。日常首选。
  • 日本节点（2）[1x]：新增日本直出线路，与（1）独立，可作为备用。解锁能力仍需持续复检。
  • cn2gia救命线路 [1.8x]：独立日本直出线路，每用 1 GB 扣 1.8 GB 配额。线路名是运营命名，中国电信 CN2 GIA 路由尚待实测证实。
  • 香港移动优化 [1x]：延迟低，流媒体走香港区。注意 ChatGPT 只能用 App，网页版不行。
  • 日本原生节点 [1.5x]：IP 记录最干净（423 个黑名单库零命中），适合对 IP 信誉敏感的场景。YouTube 会把它识别成中国大陆地区，看 YouTube 别用这个。
  • 日本原生双 ISP 家宽 [2x]：冲绳原生家宽 IP，解锁能力最强；流量仍按 1:1 扣除。

三个协议怎么选

每个节点都有三条，端口协议不同：

  • 不带后缀（VLESS-REALITY）：默认用这个，抗封锁最强
  • · HY2（Hysteria2）：走 UDP 443。网络差、丢包高、校园网或移动网络下优先试这个
  • · TUIC：HY2 的备选，HY2 不通时换它

办事指南 · 第四篇

流量规则：每月保底 60 GB，签到再加 2 GB/天

发布：MTF公益机场站务组更新：2026-09-22阅读约 3 分钟

基础配额

  • 每个账号每月保底 60 GB
  • 每月 1 号重置，用不完不累积
  • 最多 5 台设备同时在线（按同时在线的 IP 数算）

签到领流量（额外叠加）

左侧菜单「每日签到」，每天固定领 2 GB，注册后立刻就能签，没有冷却期。签到所得是在 60 GB 保底之上额外加的，一个月全勤 30 天就是 60 + 60 = 120 GB。

签到所得不跨月累积：每月 1 号重置会连同签到部分一并清掉，回到 60 GB 保底。这是故意的，鼓励每天来看看，而不是攒一整年。签到页上有「距本月重置还有 N 天」的提示。

防刷规则：同一个 IP 每天最多 3 个账号能签到。

流量怎么算

流量排行显示实际上传 + 下载流量。配额扣除另算：cn2gia救命线路按 1.8 倍，其余节点按 1:1。

速度为什么会变

我们按实测带宽负载动态调速：每账号、每来源 IP 最高 100 Mbps。连接数和低流量 IP 数都不会拿来平分带宽；有人用不到上限，别人仍可使用空余带宽。机器接近满载时逐步收紧，负载回落后放宽。没有 10 Mbps 保底，10 Mbps 是拥堵切换阈值。

另外每个 IP 有独立的动态速度上限（最高 100 Mbps）和每日 15 GB 的用量上限，防止单个人把一台机器吃满。

办事指南 · 第五篇

连不上 / 速度慢 / 某个网站打不开

发布：MTF公益机场站务组更新：2026-09-22阅读约 3 分钟

完全连不上

  1. 换协议：VLESS 不通就试 · HY2（走 UDP 443，穿透性最好），再不行试 · TUIC
  2. 更新订阅：客户端里手动点一次「更新订阅」，节点可能有变动
  3. 对时间：设备时间偏差超过 1 分钟会导致握手失败，开自动对时
  4. 换节点：某个节点可能临时下线，探活会自动把它从订阅里摘掉，更新订阅即可

能连上但很慢

  • 先看是不是流量用完了（仪表盘能看剩余）
  • 速度按实测负载调整，最高 100 Mbps；连接人数多但大家空闲时不会白白降速，实测拥堵时才调低
  • 同一个 IP 上开太多设备会互相抢带宽（单 IP 有总速率上限）
  • 试试别的节点，线路对不同地区网络质量差别很大

设备数超了

同时在线 IP 超过 5 个会被拒。注意：手机切换 Wi-Fi / 流量会换 IP，旧连接要几分钟才释放。

ChatGPT 打不开

  • 网页版请先用「日本节点（1）[1x]」；其他节点的网页版解锁状态需自行测试
  • 记得清浏览器 Cookie，并关掉「自动择优」改成固定节点

YouTube 显示中国地区

别用「日本原生节点 [1.5x]」，那个 IP 被 YouTube 判成大陆。换 1x 的日本或香港节点。

流媒体解锁

  • Netflix / Disney+ / TikTok：日本和香港节点都能解锁，但区域不同（日本节点走日区，香港节点走港区）
  • 解锁能力会随时间变化，我们每月自动复检一次

还是不行

提工单（左侧「我的工单」），带上这几样：用了哪个节点、哪个协议、客户端名字和版本、错误提示截图。
